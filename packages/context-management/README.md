# Context Management

The base Profile mounts `context-management` to prepare model requests, handle context overflow and display current context and cumulative usage. Runs supplies the selected model, assembled prompt and tool schemas. [Sessions](../sessions/README.md) owns durable history, effective context, settings and model attempts.

The token meter uses an adapter's input counts when available and estimates other requests from their actual native contents. Cached reads and writes count once toward model input. Known provider usage calibrates estimates for subsequent requests to the same model. The input budget reserves the model's response capacity and an estimation margin. The Web context ring shows the share of the entire window and its panel shows the share of the input budget.

Read-only tool results with identical contents and metadata can reference an earlier result. Large outputs use a bounded excerpt and preserve source references and spill paths. Tools can supply `pruneResult` to choose the excerpt. Historical images and inline attachments can move out of the request under pressure. The `read_context` tool fetches original text or images from the session log by entry ID. Set `raw` to retrieve tool output before any result transforms.

Automatic, manual and overflow compaction use the same token-based checkpoint selection. A checkpoint replaces a contiguous prefix at a complete tool-exchange boundary. The summary model receives the native prefix when it fits, with larger inputs processed in segments. A replacement is committed only after the resulting request validates and shrinks. Summary requests use the model transport directly, so returned tool calls are never executed.

The [configuration schema](src/server/config.ts) owns defaults and validation. Settings → General defines Profile defaults. The composer context settings control switches between following the Profile defaults and a complete custom configuration, and can compact the active conversation or cancel manual compaction. The statistics panels are read-only. Turning off automatic compaction leaves manual compaction and independent pruning available. The optional Context Management plugin can be disabled in Settings → Built-in plugins. Custom profiles use the `context-management` entry in place of `core:compaction`.

Statistics follow the selected branch. Overall usage includes known usage from retries, failed attempts and summary calls. Model time includes all recorded attempts. Tool time sums invocation durations, including overlapping calls. Turn token use includes its model steps and automatic summary calls. Older sessions retain historical usage when it is available.

# Code style

Apply these rules when writing or reviewing code. They complement the [engineering conventions](../conventions.md); examples are illustrative.

- [TypeScript nullability and invariants](typescript-nullability.md): strong types, boundary validation, and state modeling.
- [Maintainable implementation](maintainability.md): ownership, composition, error handling, async work, and readability.

- [Tests](testing.md): ownership, observable contracts, fixtures, and synchronization.
- [Module imports](module-imports.md): workspace boundaries, exports, and SDK imports.
